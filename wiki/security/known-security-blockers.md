# Known Security Blockers

No package-release security blocker is known for `0.6.0`. Alpha-Wiki is not a
security scanner and does not prove that a target project's content is safe.
Any future hosted service, remote ingestion, credential handling, or automatic
code execution would require a new security review before release.
